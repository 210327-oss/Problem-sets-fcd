# Problem Set 1 - Fundamentos de Ciencia de Datos

Este repositorio contiene el desarrollo del Problem Set 1 del curso Fundamentos de Ciencia de Datos.

El trabajo se encuentra organizado en dos carpetas principales: `p1` y `p2`.

## Carpeta p1

En esta carpeta se desarrolló la parte teórica del trabajo.

Se revisó la metodología CRISP-DM y sus etapas para el desarrollo de proyectos de ciencia de datos. También se analizó la plataforma Michelangelo de Uber y se identificó qué partes de su funcionamiento pueden relacionarse con CRISP-DM.

Además, se revisó la propuesta de Martínez-Plumed et al., que permite entender mejor proyectos de ciencia de datos donde el proceso no siempre sigue una secuencia fija y puede ser necesario regresar, explorar nuevos datos o modificar los objetivos.

El desarrollo se encuentra en:

`Parte_1.md`

## Carpeta p2

En esta carpeta se realizó el trabajo con los datos de la ENAHO.

La metodología se dividió principalmente en dos etapas: entendimiento de los datos y transformación de los datos.
